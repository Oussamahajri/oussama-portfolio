## ⚡ 1. The Core Concept

**HAJRI // DIGITAL IDENTITY** is an interactive, game-inspired portfolio designed to subvert traditional portfolio conventions. Instead of static cards and boring sections, the visitor enters an interactive digital universe representing Oussama's professional identity.

- **Cinematic Entry:** Kernel initialization sequence, decrypted identity confirmation, and instant entry via `[START EXPERIENCE]` or `[ENTER]`.
- **Three.js 3D Universe:** Real-time spatial navigation with raycasting hover telemetry, a central digital identity core with rotating orbital rings, starfield particle galaxy, and orbital module nodes.
- **Projects as Tactical Missions:** Projects are framed as strategic engineering deployments featuring Problem/Solution analyses, layered architecture diagrams, features checklist, live metrics, and tactical terminal logs.
- **Skills as Game Statistics:** Self-calibrated levels with 10-segment power bars, execution speed, conceptual depth, and architectural integration gauges.
- **AI // OUSSAMA:** Interactive neural terminal assistant with intelligent local knowledge base matching, query suggestion chips, and character-by-character typewriter streaming response.
- **The Journey (Resilience Progression):** Growth mindset game loop (`BUG FOUND -> DEBUGGING -> LESSON LEARNED -> SKILL INCREASED -> NEXT LEVEL`) showcasing real troubleshooting scenarios.
- **Recruiter Mode:** High-efficiency executive dossier with full candidate overview, skills matrix, project breakdowns, printable/save-as-PDF CV, and instant contact.
- **Developer Mode:** Deep technical inspection view with systems topology, layer diagrams (Frontend, Backend, Databases, WebGL, DevOps), and telemetry diagnostics.
- **Procedural Web Audio Engine:** In-browser synthesized sci-fi sound effects using Web Audio API (zero external MP3 links required, muted by default with HUD toggle).
- **Hidden Easter Eggs (5+):** Konami Code matrix mode, secret retro terminal, kinetic core overcharge, classified 2030 future roadmap, and DevTools console secret function.

## 🛠️ 2. Technology Stack

- **Framework:** Angular 21 (Standalone Components, Signals, RxJS)
- **3D Graphics Engine:** Three.js (WebGL2, BufferGeometry, PBR materials, Raycasting)
- **Audio Synthesis:** Web Audio API (Procedural Oscillators & Filters)
- **Styling Architecture:** SCSS Design Tokens (`_variables.scss`, `_typography.scss`, `_animations.scss`, `_mixins.scss`)
- **Typography:** Orbitron (Headings/HUD), Space Grotesk (Body), JetBrains Mono (Code/Telemetry)
- **Build Tool:** Angular CLI 21 with Vite bundler

## 🕵️ 5. Easter Eggs & Secret Achievements

1. **Konami Code Protocol:**  
   Press `↑ ↑ ↓ ↓ ← → ← → B A` anywhere on your keyboard to toggle the matrix overclock theme and unlock the **OVERCLOCK PROTOCOL** achievement.
2. **Secret Terminal Console:**  
   Press `~` or click `>_ TERMINAL` in the HUD to launch the interactive retro shell. Try running `help`, `whoami`, `skills`, `projects`, `contact`, `matrix`, `future`, `sudo`, and `cat secret.txt`.
3. **Kinetic Core Overcharge:**  
   Rapidly click the central 3D Identity Core or the top-left brand logo 5 times in quick succession to trigger an energy pulse and unlock the **CURIOSITY OVERDRIVE** achievement.
4. **Classified Future Horizon:**  
   Type `future` in the terminal or press `F` to inspect the 2026-2030 engineering roadmap and unlock the **FUTURE HORIZON** secret achievement.
5. **DevTools Console Hook:**  
   Open browser developer tools (F12) to see an ASCII terminal greeting. Inspect or execute `window.__SECRET_OVERCLOCK()` directly from the console.
